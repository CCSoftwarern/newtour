Conexão Xano API

Guia de Setup - Tabelas Xano

1

Criar Grupo no Xano

Acesse xano.com → Novo Group → Nome: newtour-api

2

Criar as Tabelas

Crie as tabelas conforme a seção "Referência de Tabelas" abaixo.

3

Criar Endpoints

Crie os endpoints CRUD para cada tabela (GET, POST, PATCH, DELETE).

4

Copiar URL Base

Copie a URL base da API e cole na configuração ao lado.
